# Morpheus

Morpheus is an open research program for **developmental, infrastructure-adaptive
language systems**.

The working hypothesis is that useful machine intelligence does not require every
fact, skill, experience, and deployment profile to be compressed into one immutable
set of weights. Instead, a stable cognitive kernel can be surrounded by:

- elastic execution profiles;
- fine-grained, loadable experts;
- evidence-backed external knowledge;
- episodic memory and reusable skills;
- latent world models;
- guarded, test-driven self-improvement.

The project advances through small, falsifiable experiments. Negative results are
first-class results.

## Public boundary

This repository intentionally contains **no private infrastructure inventory or
topology**. It never publishes hostnames, addresses, device identifiers, local paths,
service ports, credentials, raw system output, private datasets, or model weights.

Experiments describe compute through anonymous capability classes defined in
[`docs/methodology/capability-envelope.md`](docs/methodology/capability-envelope.md).
Before every publication, the repository's public-safety check must pass.

## Research tracks

1. **Morphology** — one system, multiple execution phenotypes.
2. **Experts** — discoverable, testable, loadable expert packages.
3. **Memory** — factual, episodic, procedural, and provenance-aware memory.
4. **Self-education** — research, contradiction detection, and evidence graphs.
5. **Latent cognition** — prediction and planning beyond token reconstruction.
6. **Governance** — quarantine, promotion, rollback, and anti-contamination gates.

See [`ROADMAP.md`](ROADMAP.md) for the staged program and
[`experiments/`](experiments/) for the evidence log.

## Status

The project begins in **Phase 0: measurement and falsification design**. No claim is
considered validated without a reproducible protocol and an explicit result.
